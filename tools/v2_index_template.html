Conventions
  • Par zone : manifest.yaml + raw/ (livraison brute immuable) + transformed/vecteurs/ (GPKG nettoyés, EPSG:2154) + transformed/roboflow/ (payloads d'upload + upload_manifest.yaml) + docs/.
  • Tags Roboflow par image : <zone_id> + <region> — l'export Roboflow ne préserve pas les tags, les upload_manifest.yaml locaux font foi. Sous-classes : <entite>_<site>.
  • On n'édite jamais un fichier en place sur le Drive (pas d'ArcGIS/QGIS sur G:). Ne rien supprimer sans décision humaine explicite.
  • _archives_roboflow/ = exports zip intacts · _a_trier/ = images inattribuables à une zone (à trier ou abandonner à la recréation).
